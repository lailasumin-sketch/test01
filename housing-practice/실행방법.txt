의성에서, 살다 — 첨부 CSV로 만드는 주거 검색 연습

[실행 방법]
1. 이 폴더 전체를 USB 또는 PC로 복사합니다.
2. 폴더 안의 index.html을 더블클릭합니다.
3. 최신 Chrome, Edge, Firefox, Safari 등의 브라우저로 엽니다.
4. 기본 주거연습.csv 3건은 이미 포함되어 바로 검색할 수 있습니다.
설치, CMD, 개발 서버, 인터넷 연결이 필요하지 않습니다.
ZIP 파일 안에서 직접 열지 말고 먼저 모든 파일을 압축 해제하세요.

[검색 방법]
- 희망 읍·면과 월세·보증금 상한을 선택하고 ‘조건으로 검색’을 누릅니다.
- 모든 조건은 동시에 적용됩니다. 금액은 입력한 수치 이하를 포함합니다.
- 금액 입력칸이 비어 있으면 제한하지 않습니다. 0은 0만 원 조건입니다.
- 상세보기를 누르면 파일의 네 항목을 확인할 수 있습니다.
- 없는 값은 ‘정보 없음’으로 표시합니다. 0원으로 바꾸지 않습니다.
- 금액이 없는 자료는 그 금액의 상한 조건을 설정하면 결과에서 제외합니다.
- 검색 조건 초기화로 전체 자료를 다시 봅니다.

[직접 확인할 정답]
전체: 3건
월세 45만 원 이하: 가상주택 A·B, 총 2건
보증금 500만 원 이하: 가상주택 A·B, 총 2건
안계면 + 월세 30만 원 이하: 0건
월세 35만 원 이하 + 보증금 300만 원 이하: 가상주택 A, 총 1건

[사용 데이터]
첨부된 주거연습.csv의 3건을 사용합니다.
메인 화면에서 바로 희망 조건을 선택해 검색합니다.
원본 자료를 영구적으로 변경하려면 개발자가 CSV 변경 후 빌드해야 합니다.

[파일 구성]
index.html: 설치 없이 실행하는 완성 파일
실행방법.txt: 이 안내
파일검사결과.txt: 첨부 CSV의 열·자료 수·빈값·단위 검사 결과
data/주거연습.csv: 첨부 원본 파일 그대로 보관
source/: 수정 가능한 HTML·CSS·JavaScript 원본

[주의]
모든 자료는 연습용 가상 주택입니다. 실제 매물이나 시세가 아닙니다.
주소·면적·연락처·입주 가능일 등 원본에 없는 정보는 만들지 않았습니다.
대회 사전 제작 코드 규정에 따라 이 코드는 연습용으로 사용하세요.
