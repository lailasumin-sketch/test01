# 의성에서, 살다

의성군 귀농·귀촌을 위한 읍·면별 생활 정보 탐색 웹 시제품입니다. 주거, 농산물, 지원 정보, 취업을 지역·분야·키워드로 함께 검색합니다.

## Windows USB 더블클릭 패키지

`downloads/uiseong-life-windows-usb.zip`을 모두 압축 해제한 뒤
`uiseong-life-windows-usb` 폴더 전체를 USB로 복사하고 **실행하기.bat**를 더블클릭하세요.
Windows용 자체 서버(x64·ARM64·x86), dist, 로컬 CSV 432건, 원본 코드, 실행안내서와 검증결과가 포함됩니다.
대상 PC에 Node.js·Python·Go 설치나 인터넷 연결이 필요하지 않습니다.
서버 창은 이용 중 열어 두며, 종료 시 Ctrl+C 또는 창을 닫습니다.
CSV 로딩 실패 시 내장 데이터로 대체하고 화면에 안내합니다.
Windows 직접 실행 검증은 아직 필요하며, 동봉한 검증결과에서 실제 확인 항목과 구분했습니다.

개발용 생성 명령:

```sh
npm run build:usb
python3 scripts/package-windows-usb.py --go /path/to/official/go
python3 scripts/audit-usb.py usb-submission
```

기존 GitHub 연결과 Vercel 설정은 그대로 유지합니다.

## USB에 전체 서비스 저장하기

`downloads/uiseong-life-full-usb.zip`이 네 분야 전체를 포함한 USB 패키지입니다.
압축을 모두 풀고 `uiseong-life-full` 폴더 전체를 USB로 복사한 뒤, 그 폴더 맨 위의 `index.html`을 여세요.
주거·농산물·지원·취업, 맞춤 검색, 관심 정보, 전체 가상데이터 432건이 포함되어 있습니다.
파일 확인·CSV 불러오기 화면은 없습니다.
실행 안내, 원본 코드와 테스트, 전체 데이터 JSON·CSV 사본도 포함됩니다.
외부 경로나 서버 없이 실행되며 공식 사이트로 이동할 때만 인터넷이 필요합니다.

패키지 다시 만들기: `npm run build` 다음 `python3 scripts/package-full.py`.

## 가장 쉽게 실행하기

1. GitHub 저장소에서 **Code → Download ZIP**을 선택하세요.
2. 다운로드한 ZIP 파일을 압축 해제하세요.
3. 폴더 안의 **index.html을 더블클릭**해 최신 Chrome, Edge, Safari 등으로 여세요.

별도 설치나 서버가 필요 없습니다. 화면과 검색은 인터넷 연결 없이 작동하며, 공식 사이트 링크를 열 때만 인터넷이 필요합니다. 관심 정보의 새로고침 후 유지 여부는 브라우저의 로컬 파일 저장소 정책에 따라 달라질 수 있습니다.

## 구현된 기능

- 의성군 1읍·17면 선택 및 주거·농산물·지원·취업 분야 탐색
- 희망 생활 문장 입력 → 인식된 조건 확인·수정 → 맞춤 검색
- 월세·보증금 상한, 관심 작목, 지원 대상, 근무 형태, 시급 하한, 추가 키워드
- 분야별 108건씩 총 432건의 가상데이터와 조건·금액 표시
- 지역·분야·키워드 결합 검색, 결과 더 보기, 필터 초기화
- 관심 정보 저장(localStorage, 이 브라우저에만 보관)
- 상세 안내와 공식 사이트 연결
- 모바일 화면, 키보드 접근, 모달 닫기, 빈 검색 결과

## 맞춤 검색 사용법

1. ‘어떤 의성 생활을 원하세요?’ 입력창에 희망 생활을 적습니다.
2. ‘문장에서 조건 가져오기’를 누르고 아래 선택 항목에 반영된 내용을 확인합니다.
3. 필요한 조건을 수정하고 ‘내 조건으로 검색하기’를 누릅니다. 문장 입력 없이 항목을 직접 선택해도 됩니다.
4. 결과 위에 적용된 조건과 분야별 결과 수가 표시됩니다.

예시: `안계면에서 월세 50만 원 이하 집, 초보 교육과 주말 일자리를 찾고 싶어요.`

지역·분야·월세·보증금·작목·지원 대상·근무 형태·시급을 정해진 표현으로 인식하는 규칙 기반 기능입니다. 외부 AI를 호출하지 않으며 문장 전체를 이해하지 않습니다. 인식하지 못한 표현은 적용되지 않으므로 가져온 조건을 확인해야 합니다. 금액의 단위는 반드시 입력하세요. 월세·보증금은 이하, 시급은 이상 조건을 지원합니다. 여러 지역·작목·지원 대상·근무 형태를 한 문장에 넣으면 하나씩 선택하도록 안내합니다.

주거비 조건은 주거에, 작목은 농산물에, 지원 대상은 지원 정보에, 근무 형태·시급은 취업에만 적용됩니다. 함께 찾을 분야는 여러 개 선택할 수 있습니다. 분야를 선택하지 않으면 조건에 해당하는 분야를 자동 선택합니다. 특정 지원 대상 검색에는 ‘누구나’ 대상 예시도 포함됩니다. 키워드와 검색 결과 영역의 필터는 모든 결과에 추가 적용됩니다. 모든 조건 초기화는 결과 영역의 ‘필터 초기화’로 가능합니다.

432건은 18개 읍·면마다 네 분야별 6개 유형으로 구성한 결정적 예시 데이터입니다. 금액, 근무 조건, 지원 대상, 지역 배치는 전부 가상이며 실제 시세·최저임금 안내·자격 판정·지역 농업 통계가 아닙니다.

## 수정 및 개발

원본 화면은 `src/page.html`, 스타일은 `src/style.css`, 동작은 `src/app.js`, 예시 데이터는 `src/data.js`에 있습니다.

Node.js 18 이상에서 외부 패키지 설치 없이 아래 명령으로 단일 실행 파일을 다시 만들고 테스트할 수 있습니다.

```sh
npm run build
npm test
```

개발 서버가 필요하면 Python 3을 설치한 상태에서 `npm start`를 실행하세요. 3000번 포트를 사용합니다.

## 데이터와 범위

**모든 정보 카드는 예시입니다.** 실제 주택 매물, 채용 공고, 모집 중인 지원사업이 아니며 지역별 작목 분포를 증명하지 않습니다. 주거비와 시급은 가상 금액입니다. 실제 가격·지원금·접수기간·연락처는 등록하지 않았습니다. 공식 링크는 개별 공고가 아닌 사이트 첫 화면으로 연결됩니다. 메인 이미지는 CSS 일러스트이며 지도가 아닙니다.

실서비스 전환에는 공식 데이터 제공처와 이용 조건 확인, 수집/갱신 서버, 원문·확인일·마감일·지역 좌표, 실제 지도 연동이 필요합니다. 로그인, 사용자 간 동기화, 매물 등록, 실시간 수집은 아직 구현하지 않았습니다. API 키나 데이터베이스는 필요하지 않습니다.


## 첨부 CSV 기반 주거 검색 실습

별도의 `housing-practice` 폴더는 사용자 첨부 `주거연습.csv` 3건만 사용합니다. 기존 432건 가상데이터 서비스와 분리되어 있습니다.

- USB 실행: `housing-practice/index.html` 더블클릭
- 묶음 파일: `downloads/housing-practice.zip` (압축 해제 후 실행)
- 원본 검사 결과: `housing-practice/파일검사결과.txt`
- 사용 안내: `housing-practice/실행방법.txt`
- 재생성: `npm run build:housing`
- 검사: `npm test` (파일 파싱·필터·빈값 처리 테스트 포함)

읍·면, 주택명, 월세, 보증금만 사용합니다. 메인 화면은 희망 조건 검색과 검색 결과로 구성되며, 파일 검사·불러오기 기능은 표시하지 않습니다. 없는 값은 ‘정보 없음’으로 표시합니다. 기본 첨부 자료는 HTML에 포함되어 서버나 인터넷이 필요하지 않습니다.


## Vercel 배포

저장소의 `vercel.json`에 빌드 명령 `npm run build`와 출력 폴더 `public`이 지정되어 있습니다.
빌드는 USB용 `index.html`과 배포용 `public/index.html`을 함께 생성합니다.
Vercel 프로젝트는 저장소 루트를 Root Directory로 사용하세요.
`public`은 생성 결과이므로 Git에 포함하지 않습니다.
