# 의성에서, 살다

의성군 귀농·귀촌을 위한 읍·면별 생활 정보 탐색 웹 시제품입니다. 주거, 농산물, 지원 정보, 취업을 지역·분야·키워드로 함께 검색합니다.

## 가장 쉽게 실행하기

1. GitHub 저장소에서 **Code → Download ZIP**을 선택하세요.
2. 다운로드한 ZIP 파일을 압축 해제하세요.
3. 폴더 안의 **index.html을 더블클릭**해 최신 Chrome, Edge, Safari 등으로 여세요.

별도 설치나 서버가 필요 없습니다. 화면과 검색은 인터넷 연결 없이 작동하며, 공식 사이트 링크를 열 때만 인터넷이 필요합니다. 관심 정보의 새로고침 후 유지 여부는 브라우저의 로컬 파일 저장소 정책에 따라 달라질 수 있습니다.

## 구현된 기능

- 의성군 1읍·17면 선택 및 주거·농산물·지원·취업 분야 탐색
- 지역·분야·키워드 결합 검색, 결과 더 보기, 필터 초기화
- 관심 정보 저장(localStorage, 이 브라우저에만 보관)
- 상세 안내와 공식 사이트 연결
- 모바일 화면, 키보드 접근, 모달 닫기, 빈 검색 결과

## 수정 및 개발

원본 화면은 `src/page.html`, 스타일은 `src/style.css`, 동작은 `src/app.js`, 예시 데이터는 `src/data.js`에 있습니다.

Node.js 18 이상에서 외부 패키지 설치 없이 아래 명령으로 단일 실행 파일을 다시 만들고 테스트할 수 있습니다.

```sh
npm run build
npm test
```

개발 서버가 필요하면 Python 3을 설치한 상태에서 `npm start`를 실행하세요. 3000번 포트를 사용합니다.

## 데이터와 범위

**모든 정보 카드는 예시입니다.** 실제 주택 매물, 채용 공고, 모집 중인 지원사업이 아니며 지역별 작목 분포를 증명하지 않습니다. 가격·지원금·접수기간·연락처는 등록하지 않았습니다. 공식 링크는 개별 공고가 아닌 사이트 첫 화면으로 연결됩니다. 메인 이미지는 CSS 일러스트이며 지도가 아닙니다.

실서비스 전환에는 공식 데이터 제공처와 이용 조건 확인, 수집/갱신 서버, 원문·확인일·마감일·지역 좌표, 실제 지도 연동이 필요합니다. 로그인, 사용자 간 동기화, 매물 등록, 실시간 수집은 아직 구현하지 않았습니다. API 키나 데이터베이스는 필요하지 않습니다.
