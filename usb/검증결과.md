# USB 패키지 검증 결과

## 실제 실행해 통과한 항목

| 구분 | 실행 및 결과 |
|---|---|
| 프레임워크·정적 빌드 | HTML/CSS/JavaScript 기반. Node.js 없이 실행 가능한 USB dist 생성 |
| 데이터·검색 테스트 | 프로젝트 테스트 25개 통과. USB CSV 왕복·금액·누락값·중복 ID·잘못된 값·부적절한 링크 검사 포함 |
| Windows 바이너리 생성 | 공식 체크섬 검증 Go 1.27.3으로 amd64·arm64·386 크로스컴파일 성공. PE32/PE32+ Windows 10 형식 확인 |
| 서버 실제 구동 | 동일 Go 소스의 Linux amd64 빌드를 실제 실행. 준비 상태·HTML·CSV 정상 응답 |
| 상대 경로 | 다른 작업 디렉터리에서 실행. 실행파일 위치로 dist 탐색. 한글·공백·&·!·괄호가 포함된 경로에서 성공 (Linux) |
| 포트 충돌 | 선호 포트를 다른 소켓이 점유한 상태에서 다른 포트로 시작 성공 |
| 중복 시작 | 같은 자료의 기존 서버를 재사용하고 새 프로세스가 정상 종료하는 것 확인 |
| 종료 | Ctrl+C에 해당하는 SIGINT로 서버 정상 종료 (Linux) |
| 접근 제한 | 경로 탈출·dist 외부 심볼릭 링크·소스 디렉터리·폴더 목록·숨김 경로 404, POST 405, 다른 Host 403 확인 |
| 오프라인 가정 | Chromium에서 127.0.0.1만 허용하고 다른 네트워크 요청은 차단. 실제 로컬 CSV HTTP 200 확인. 외부 요청 0건·JavaScript 오류 0건 |
| 전체 기능 | 432건/네 분야, 안계면 24건, 농산물+마늘 18건, 복수 분야 맞춤 검색 8건 확인 |
| 관심·상세 | 하트 저장 후 새로고침 유지, 관심 목록·상세 모달·Escape 닫기 확인 |
| 결과 조작 | 더 보기·빈 검색 결과·조건 초기화 확인 |
| CSV 실제 이용 | CSV 제목을 임시 수정한 후 새로고침해 변경된 내용이 화면에 반영됨을 확인 |
| CSV 오류 대체 | 잘못된 CSV와 CSV 요청 실패 각각에서 내장 432건 대체와 안내 확인 |
| 안전한 텍스트 | CSV 제목에 HTML 태그를 넣어도 이미지/스크립트로 실행되지 않고 문자로 표시되는 것 확인 |
| 금액 누락 | 빈 월세를 ‘정보 없음’으로 표시. 금액 조건에서 누락값을 0으로 취급하지 않는 테스트 통과 |
| 모바일 | 360/390/768px 화면 가로 넘침 없음 |
| 비밀정보 점검 | 명시한 파일만 패키징. .env·.git·개인 인증파일 제외. 알려진 토큰/API키/개인키/인증 URL 패턴 검사에서 탐지 0건 |
| 최종 ZIP·원본 재빌드 | 압축 해제 후 모든 SHA-256 검증. 동봉 원본 테스트 17개 통과. 동봉 원본에서 USB dist·CSV 재생성 결과와 배포용 public 생성 확인 |
| 연결 설정 유지 | 기존 origin과 vercel.json 변경 없음. 기존 Vercel용 public 빌드도 유지 |

실제 HTTP 기능 검증에는 동일 서버 소스의 Linux 실행파일을 사용했습니다.
Windows EXE는 크로스컴파일 및 파일 형식을 확인한 상태이며, Windows에서 실행한 결과가 아닙니다.
인터넷 차단은 브라우저 요청 정책으로 외부 호스트만 차단한 모의 검증입니다.
심사 PC의 네트워크 어댑터를 물리적으로 끈 테스트는 아닙니다.
패턴 검사는 모든 형태의 비밀정보가 없음을 수학적으로 보증하지는 않으며,
생성 데이터·허용 목록으로 선정한 코드·자체 컴파일 서버만 포함했는지도 함께 검토했습니다.

## Windows PC에서 추가 검증이 필요한 항목

이 개발 환경에는 Windows 및 Wine/Windows PowerShell 실행 환경이 없어 아래는 미실행입니다.

- Windows 10/11 실제 USB에서 실행하기.bat 더블클릭
- x64·ARM64·x86별 해당 EXE 선택과 구동
- 기본 브라우저 자동 열기와 파일 연결 정책
- USB 드라이브 문자가 바뀌거나 한글·공백이 있는 Windows 경로에서 실행
- Windows Defender·SmartScreen·기관 보안 정책의 BAT/서명 없는 EXE 허용 여부
- 다른 프로그램이 포트를 사용 중일 때 Windows에서의 대체 포트 선택
- 배치 콘솔 종료/Ctrl+C 시 Windows 서버 종료
- 실제 PC의 Wi-Fi/유선 네트워크를 끈 상태에서 CSV·맞춤 검색·관심 저장
- 제출 PC 브라우저의 localStorage 허용 및 포트별 저장 유지

위 항목은 ‘미실행’이며 통과했다고 보고하지 않습니다.
별도 런타임 설치가 불필요한 구성은 완성했지만, 최종 제출 전 Windows 실기기 확인이 필요합니다.
