의성에서, 살다 — 심사위원용 USB 실행안내서

1. 실행
- ZIP 파일을 먼저 ‘모두 압축 풀기’로 해제합니다.
- uiseong-life-windows-usb 폴더 전체를 USB 또는 PC의 원하는 위치로 복사합니다.
- 폴더 맨 위의 ‘실행하기.bat’를 더블클릭합니다.
- 기본 브라우저가 열리고 의성군 생활 정보 검색 화면이 나타납니다.
- Node.js, Python, Go 설치나 인터넷 연결, 관리자 권한은 필요하지 않습니다.
- Windows 10/11과 최신 Edge 또는 Chrome 사용을 권장합니다.
- x64·ARM64·x86용 서버를 포함하고 배치파일이 OS 종류에 맞춰 선택합니다.

2. 실행 중과 종료
- 검은 서버 창은 이용 중 열어 두세요. 최소화해도 됩니다.
- 종료하려면 서버 창에서 Ctrl+C를 누르거나 창을 닫습니다.
- 실행 중에는 USB를 뽑지 마세요. 종료 후 안전하게 제거합니다.
- 반복 더블클릭 시 같은 버전의 서버가 실행 중이면 그 서버 화면을 다시 엽니다.
- 브라우저가 열리지 않으면 서버 창의 READY 뒤 주소를 복사해 주소창에 입력합니다.
- 기본 주소는 http://127.0.0.1:18765/이며, 포트 충돌 시 다른 포트가 자동 선택됩니다.
- 주소는 이 컴퓨터 내부에서만 동작합니다. Wi-Fi나 인터넷 연결은 필요하지 않습니다.

3. 주요 심사 기능
- 18개 읍·면과 주거·농산물·지원·취업 네 분야를 탐색합니다.
- 전체 가상자료 432건, 분야별 108건입니다.
- 읍·면 선택, 키워드 검색, 분야 필터, 결과 더 보기, 상세보기를 사용할 수 있습니다.
- 희망 생활을 입력하고 ‘문장에서 조건 가져오기’를 누릅니다.
  인식된 조건을 확인·수정한 뒤 ‘내 조건으로 검색하기’를 누릅니다.
- 예시: 안계면에서 월세 50만 원 이하 집, 초보 교육과 주말 일자리를 찾고 싶어요.
- 월세·보증금 상한은 주거, 작목은 농산물, 지원 대상은 지원 정보,
  근무 형태·시급 하한은 취업에 각각 적용됩니다.
- 하트로 관심 정보를 저장합니다. 브라우저와 포트가 같으면 새로고침 후에도 유지됩니다.
- 관심 정보는 USB가 아니라 해당 PC의 브라우저 저장소에 저장됩니다.
- 문장 검색은 규칙 기반이며 외부 AI API를 호출하지 않습니다.

4. CSV와 오프라인
- 실행 시 dist\data\records.csv를 해당 PC의 로컬 서버에서 읽어 검색합니다.
- CSV에는 주거비·작목·지원 대상·근무 조건 등 가상자료 432건이 있습니다.
- 모든 수치·자료·지역 배치는 시연용이며 실제 공고나 시세가 아닙니다.
- CSV를 정상적으로 수정하면 브라우저 새로고침 시 반영됩니다.
- CSV 형식 오류나 읽기 실패 시 내장 432건으로 대체하며 화면 상단에 안내합니다.
- API 키와 외부 API 연결 없이 메인 화면과 검색·상세·관심 저장이 동작합니다.
- 공식 사이트 링크는 참고용입니다. 링크를 열 때만 인터넷이 필요합니다.
- dist\index.html 직접 열기도 가능하지만 브라우저 정책상 CSV를 못 읽으면
  내장 자료로 동작하므로 정식 CSV 시연은 실행하기.bat를 사용해 주세요.

5. 문제가 생기면
- 파일이 없다는 오류: ZIP에서 직접 실행하지 말고 모든 파일을 압축 해제하세요.
- 브라우저 자동 열기 실패: 서버 창에 표시된 READY 주소를 직접 여세요.
- 포트 문제: 18765~18794 포트를 자동으로 시도합니다. 실행 중인 기존 창도 확인하세요.
- Windows SmartScreen·백신·기관 정책이 서명 없는 자체 제작 EXE/BAT를 차단할 수 있습니다.
  보안 정책을 우회하거나 끄지 말고 대회 담당자에게 실행 허용 여부를 확인해 주세요.
  서버 실행을 허용받기 어려우면 dist\index.html로 내장 자료 기반 화면 시연이 가능합니다.
- Windows 실행은 이 개발 환경에서 직접 검증하지 못했습니다.
  제출 전에 실제 Windows PC에서 한 번 더 점검해 주세요.

6. 폴더 구성
실행하기.bat: 서버 실행과 브라우저 자동 열기를 시작하는 파일
runtime\: Windows x64·ARM64·x86용 독립 서버 EXE
runtime\LICENSE-Go.txt: Go 표준 라이브러리 라이선스
dist\: 정적 화면과 로컬 CSV/JSON 데이터
source\: 수정·재빌드 가능한 원본 코드 (일반 실행 시 사용하지 않음)
검증결과.md: 실행 확인 결과와 Windows 추가 점검 사항
구조분석.md: 프레임워크·빌드·오프라인 구조
SHA256SUMS.txt: 패키지 내 파일 무결성 확인용 목록

7. 사전 점검 예시
- 전체 결과가 432건인지 확인합니다.
- 안계면을 선택하면 24건인지 확인합니다.
- 농산물 분야에서 마늘을 검색하면 전체 지역 기준 18건인지 확인합니다.
- 상세보기와 관심 저장, 새로고침 후 유지 여부를 확인합니다.
- 유선·Wi-Fi 연결 없이 위 기능이 동작하는지 확인합니다.
